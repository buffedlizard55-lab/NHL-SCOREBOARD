What this is

A single, always-up-to-date scoreboard for every NHL game — today's slate, live play-by-play, box scores, standings, full-season browsing for all 32 clubs, and game history verified all the way back to the league's first game (December 19, 1917). It exists so you never have to manually check multiple sites again: one page, refreshed automatically, fed by the current official league feed.

Every number on this site comes from the NHL's own official public API (api-web.nhle.com — the same service behind nhl.com/scores and the NHL.com Game Center). This project stores, caches, and displays that data; it never edits or invents it. Each game links back to its official NHL.com Game Center page for manual review.

How the data gets here

  1. A scheduled job (GitHub Actions, every 5 minutes) calls the official NHL endpoints directly, server-side.
  2. The responses are committed to this repository as static JSON; GitHub Pages republishes the branch automatically — a fresh first-party snapshot with no middleman. The live week window is stored verbatim; season indexes and the historical date archive are stored as projections (every field copied unchanged from the official response; only irrelevant fields like betting odds are dropped, and each file records its exact official source URL).
  3. Your browser loads those snapshots. For data beyond the snapshot, it asks the NHL API directly and, because the NHL API sends no cross-origin (CORS) permission for third-party sites, falls back to transparent pass-through transports. The source URL is always shown, so you can verify.

Known limitations (flagged for review)

  • Refresh cadence: the snapshot rebuilds every 5 minutes (GitHub Actions' finest cron). Live games are therefore at most ~5 minutes behind the official feed.
  • CORS: the NHL APIs send no Access-Control-Allow-Origin header (verified via raw header inspection on 2026-09-25), so a static site cannot read them directly from your browser. Both public pass-through relays were re-checked on 2026-09-25 and were down (HTTP 520/522) — this is exactly why everything the site must show reliably is snapshotted server-side.
  • Archive depth: the local archive currently covers the current and previous season in full (plus the live week). For anything older, the site links straight to the official NHL.com Game Center and raw official JSON for every game. Deeper backfill is on the roadmap.
  • Season browser: the club picker lists today's 32 franchises (from the official standings). Relocated/franchised history stays under its historical abbreviation at the official API (e.g. the Whalers are HFD, not CAR; CAR/19851986 correctly returns an empty list). Any date in history is still reachable from the Scores tab.
  • 2004-05: the season was cancelled — the official API returns 404 — so it does not appear in the season picker.
  • Scheduled workflows: GitHub disables cron workflows after 60 days of repository inactivity; re-enable from the Actions tab if the snapshot stops refreshing.
  • Anomaly flagged 2026-09-25: api.nhle.com/stats/rest/en/score/scores (the historical stats-API scores report) returns HTTP 404 while other reports on the same domain work. Not relied on by this site.
  • Preseason & special events are included when the official feed serves them.
