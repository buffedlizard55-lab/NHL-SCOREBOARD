What this is

A single, always-up-to-date scoreboard for every NHL game — today's slate, live play-by-play, box scores, standings, and full game history (verified back to at least the 2009–10 season). It exists so you never have to manually check multiple sites again: one page, refreshed automatically, fed by the current official league feed.

Every number on this site comes from the NHL's own official public API (api-web.nhle.com — the same service behind nhl.com/scores and the NHL.com Game Center). This project stores, caches, and displays that data; it never edits or invents it. Each game links back to its official NHL.com Game Center page for manual review.

How the data gets here

  1. A scheduled job (GitHub Actions, every 5 minutes) calls the official NHL endpoints directly, server-side.
  2. The responses are written into this site as static JSON and redeployed — a fresh first-party snapshot.
  3. Your browser loads those snapshots. For older games beyond the snapshot window, it asks the NHL API directly and, because the NHL API sends no cross-origin (CORS) permission for third-party sites, falls back to transparent pass-through transports. The source URL is always shown, so you can verify.

Known limitations (flagged for review)

  • Refresh cadence: the snapshot rebuilds every 5 minutes (GitHub Actions' finest cron). Live games are therefore at most ~5 minutes behind the official feed.
  • CORS: the NHL APIs send no Access-Control-Allow-Origin header (verified via raw header inspection on 2026-09-25), so a static site cannot read them directly from your browser. Snapshot + documented fallbacks handle this.
  • Scheduled workflows: GitHub disables cron workflows after 60 days of repository inactivity; re-enable from the Actions tab if the snapshot stops refreshing.
  • Anomaly flagged 2026-09-25: api.nhle.com/stats/rest/en/score/scores (the historical stats-API scores report) returns HTTP 404 while other reports on the same domain work. Not relied on by this site.
  • Preseason & special events are included (the official feed serves them); very old eras before the API's history window are out of scope.
